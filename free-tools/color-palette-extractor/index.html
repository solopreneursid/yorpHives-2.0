Color Palette Extractor

Extract a dominant color palette from an image, preview swatches and copy HEX values.

Choose an image to extract its dominant colors.

How this tool works

The image is decoded and sampled locally using a canvas. Transparent pixels are ignored. Palette extraction is an approximate frequency-based color quantization, not a perceptual clustering algorithm.
