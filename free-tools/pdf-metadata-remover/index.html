PDF Metadata Remover

Remove common document information fields and embedded XMP metadata from a PDF locally in your browser.

Choose a PDF to inspect and clean its document metadata.

How this tool works

Processing happens in this browser using pdf-lib loaded from jsDelivr. This clears standard document information fields and the catalog XMP metadata stream. It does not remove names, comments, annotations, signatures, hidden content, text, image EXIF data inside attachments, or filesystem metadata. Re-saving can invalidate digital signatures. Keep the original file.
